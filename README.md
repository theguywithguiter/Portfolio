# 💻 Subham Datta — Developer Portfolio

A modern, responsive developer portfolio built with **React.js and Vite**, designed to showcase my projects, technical skills, internships, certifications, and development experience.

The portfolio features a bold modern UI, responsive layouts, smooth navigation, interactive sections, and a project-focused presentation.
